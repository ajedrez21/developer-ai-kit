# ADR 0001 — Core canónico del Developer AI Kit

- **Core** independiente del dashboard TL. Contrato `team-ai/v1` import/export JSON.
- **Runtime** Node.js ≥ 20.19.0. Scripts esenciales en TypeScript compilado; hooks `.cjs` para Windows/Linux sin Bash/symlinks.
- **OpenSpec** se reutiliza; wrappers `/work-*` añaden Azure, aprobación y gates.
- **Seguridad** vía adaptador a `security-compliance` 1.0.0. Review no modifica código; fix es otra skill.
- **Fingerprint** SHA-256 + RFC 8785. Identidad Git separada del hash de contenido.
- **Enforcement** scripts + CI + branch policies. Prompts solos no bloquean merge.
- Versión fijada: `VERSION` = 1.0.0. Un update no cambia de versión sin registrarlo en el manifiesto.
